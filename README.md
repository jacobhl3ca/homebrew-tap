# jacobhl3ca/tap

Homebrew tap for my macOS apps.

## TidyTab

A tiny menu-bar app that bulk pins, unpins, or closes your Safari tabs. Signed and notarized, free.
More at [tidytab.jacobhl.com](https://tidytab.jacobhl.com) · source in
[safari-pinned-tab-automation](https://github.com/jacobhl3ca/safari-pinned-tab-automation).

```bash
brew install --cask jacobhl3ca/tap/tidytab
```

The cask always installs the latest release. TidyTab needs Accessibility permission on first run:
System Settings → Privacy & Security → Accessibility → enable TidyTab.
